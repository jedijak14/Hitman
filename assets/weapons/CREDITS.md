# Rifle asset

- `sniper-rifle.glb` is the `sniper_rifle.glb` model from the `zees-games/arena-weapons` repository, tag `v1.4.0`, commit `d96dd14bb90f680e9a034545aa60c35be41bb81d`. The repository credits the model to Styloo's free “GLTF FBX V1.1” release and records **CC0 1.0 Universal**; see [`UPSTREAM-CREDITS.md`](UPSTREAM-CREDITS.md) and the [source project](https://github.com/zees-games/arena-weapons).
- `sniper-charcoal.png` is a neutral graphite derivative of the rifle's embedded CC0 texture. The geometry is unchanged. Regenerate it together with the rose polo atlas using `python3 tools/recolor-player-textures.py` (requires Pillow).

The asset is used as a fictional long-range rifle; no proprietary firearm/game model is included.
