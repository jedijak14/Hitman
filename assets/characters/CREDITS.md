# Character model credits and licences

These bundled human models are unmodified GLB files from the public `kunalkushwaha/vsim` character library, pinned to commit [`3f97faf85e46d2f9a122b0a8b8d3ccc0af598f91`](https://github.com/kunalkushwaha/vsim/tree/3f97faf85e46d2f9a122b0a8b8d3ccc0af598f91/packages/assets/library).

| Local file | Upstream file | Source / licence |
|---|---|---|
| `human.glb` | `packages/assets/library/human.glb` | MakeHuman / MPFB2 generated human, CC0 1.0 |
| `man.glb` | `packages/assets/library/man.glb` | MakeHuman / MPFB2 generated human, CC0 1.0 |
| `suited.glb` | `packages/assets/library/suited.glb` | MakeHuman / MPFB2 generated man with fitted casual-suit and shoe geometry, CC0 1.0 |

The model, skin and clothing texture terms are documented in the upstream [`CREDITS.md`](https://github.com/kunalkushwaha/vsim/blob/3f97faf85e46d2f9a122b0a8b8d3ccc0af598f91/packages/assets/library/CREDITS.md). The bundled walk animation is described there as CMU Graphics Lab Motion Capture Database data, free for all uses. This project uses the original GLB files locally; it does not fetch character assets from a runtime CDN.
